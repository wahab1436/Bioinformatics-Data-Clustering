# Bioinformatics Data Clustering Project

A simple yet powerful **data science project** that clusters gene/protein expression data using **K-Means**, with interactive **2D and 3D visualizations**. The project automatically generates **plain English insights**, making patterns in the data easy to understand—even without complex math.

---

## 🚀 Features

- **K-Means Clustering:** Groups samples based on gene/protein expression.
- **Dimensionality Reduction (PCA):** 2D and 3D visualization of clusters.
- **Automatic Insights:** Generates simple English summaries for each cluster.
- **Interactive Dashboard:** Built with **Streamlit** for exploring clusters and genes.
- **User-Friendly:** No advanced math required to understand the results.

---

## 🛠️ Tools & Libraries

- Python  
- Pandas  
- NumPy  
- Scikit-learn (KMeans, PCA, StandardScaler)  
- Matplotlib & Seaborn  
- Plotly (for 3D visualization)  
- Streamlit
